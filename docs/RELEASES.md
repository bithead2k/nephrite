# Nephrite Releases

Release notes document the user-visible changes in each Nephrite version.
Minor releases preserve the existing vault index unless their notes say
otherwise.

## Release notes

- [0.11.0](release-0.11.md) — journal visibility, preview printing, faster
  drag interactions, and reusable context menus.
- [0.10.0](release-0.10.md) — faster pane switching, retained pane state,
  deferred preview hydration, and incremental workspace updates.
- [0.9.0](release-0.9.md) — lower editor latency, coalesced background work,
  and keystroke-path regression protection.
- [0.8.0](release-0.8.md) — plugin compatibility, expanded Tasks support,
  and safer vault writes.
- [0.7.0](release-0.7.md) — Obsidian Bases, structured properties, workspace
  tools, and plugin settings compatibility.
- [0.6.0](release-0.6.md) — responsive editing, incremental reconciliation,
  and faster large-vault link handling.
- [0.5.0](release-0.5.md) — native daily-note and file workflows, richer
  navigation, safe link resolution, and community plugin management.
- [0.4.0](release-0.4.md) — broad Dataview DQL/DataviewJS compatibility,
  typed inline fields, and stricter PostgreSQL behavior.
- [0.3.0](release-0.3.md) — note transclusion, incremental previews, and
  reliable current-page query context.
- [0.2.0](release-0.2.md) — Git workflows, vault navigation, Canvas editing,
  and expanded Vim configuration.
